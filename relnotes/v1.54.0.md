### New features

* [#430](https://github.com/rubocop/rubocop-ast/pull/430): Add `MethodDispatchNode#command_call?`, for calls with arguments and no parentheses around them. ([@bbatsov][])
* [#433](https://github.com/rubocop/rubocop-ast/pull/433): Add `ProcessedSource.default_parser_engine`, which returns the engine that `:default` stands for with a Ruby version, and `ProcessedSource.parser_gem_available?`. ([@bbatsov][])

### Bug fixes

* [#422](https://github.com/rubocop/rubocop-ast/issues/422): Fix the `prism` parser engine accepting an invalid regexp whose interpolations are all string literals, like `/#{"["}/`. ([@bbatsov][])

### Changes

* [#422](https://github.com/rubocop/rubocop-ast/issues/422): Make `prism` the default parser engine for Ruby 3.3+ when Prism 2.0 or later is installed; `parser_prism` stays the default with an older Prism. ([@bbatsov][])

[@bbatsov]: https://github.com/bbatsov
